# OPS 設備追蹤

Someplace Studio 永和空間（14.5 坪）的設備清單追蹤工具。
靜態網頁 PWA，部署在 GitHub Pages，資料存在同一個 repo 的 `data.json`。
獨立運作，不依賴任何外部服務或後端。

流程：**選品 → 設計師確認 → 夥伴確認 → 進場**

## 功能

- 依分區（接待區／攝影棚區／梳化間／廁所／辦公室）切換清單
- 每項設備記錄品牌、品名、價格、數量、尺寸、顏色材質、規格備註、商品連結、照片
- 8 段狀態流程（待確認 → 已安裝／退回重選），自動留下狀態變更時間軸
- 設計師 / 夥伴各一格意見欄，可標記「已確認 / 需討論」並留言
- 卡片可編輯、刪除，也可用左側握把拖曳排序
- 頂部即時累計金額與各狀態占比長條圖
- 多人多機共用同一份清單，前景每 20 秒自動同步一次
- 可加到手機主畫面，離線也能看（離線時的改動會暫存，連上網自動送出）

## 資料怎麼存、怎麼同步

清單存在這個 repo 的 `data.json`，照片存在 `photos/`。

| | 需要什麼 |
| --- | --- |
| **檢視** | 只要連結。不用登入、不用權杖、不用帳號 |
| **編輯** | 一組 GitHub 細粒度權杖，在網頁右上角「設定」貼上 |

純靜態網站沒有後端，寫入一定要有身分憑證，所以編輯才需要權杖。權杖存在該裝置的瀏覽器 localStorage，每台裝置貼一次即可。

**同步與衝突**：改動先存本機、畫面立即更新，停手 2.5 秒後才寫回 GitHub（避免每點一下就產生一個 commit）。寫入時帶上檔案的 blob SHA，若別人搶先改過，GitHub 回 409，此時會重新抓取、**逐筆比對 `updatedAt` 合併**、再送一次，最多重試 4 次。兩個人改不同項目不會互相覆蓋；改同一項目則以較晚的為準。刪除用墓碑紀錄（保留 90 天），否則合併時被刪的項目會從對方那邊復活。

## ⚠️ 這個做法的代價，用之前先知道

- **免費帳號的 GitHub Pages 需要 public repo，所以清單內容是公開的。** 價格、廠商、規格備註全世界都讀得到，也可能被搜尋引擎索引。不想公開就要升級 GitHub Pro（可用 private repo 的 Pages），或改用有後端的方案。
- **權杖等於這個 repo 的寫入權。** 能打開那台瀏覽器的人就能拿到它。共用電腦請用完按「清除權杖」。權杖務必用 fine-grained、只授權這一個 repo、只給 `Contents: Read and write`。
- **每次修改都是一個 commit。** 好處是完整歷史、可還原、看得出誰改的；壞處是 commit 數會長得很快。
- 同步是 20 秒輪詢，不是即時推播。兩人同時盯著看時，對方的改動最多 20 秒後才出現。

## 部署

1. 在 GitHub 建一個 **public** repo
2. 把這個資料夾推上去（見下方指令）
3. repo 的 **Settings → Pages** → Source 選 `Deploy from a branch`，branch `main`、資料夾 `/ (root)`
4. 約一分鐘後上線於 `https://<帳號>.github.io/<repo>/`
5. 第一次進去是唯讀。按右上角「設定」，依畫面指示建立權杖並貼上，即可編輯

repo 位置由網址自動判斷，不用改任何設定檔。本機開發時無法自動判斷，在設定面板手動填 `帳號/repo` 即可。

## 本機開發

Service Worker 與 ES modules 都不能在 `file://` 下運作，要用 HTTP：

```bash
python3 -m http.server 8080
```

開 http://localhost:8080，在設定面板填入 `帳號/repo` 指向線上的資料。

改版後如果瀏覽器還是舊畫面，把 `sw.js` 裡的 `VERSION` 加一再推一次。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 版面與樣式 |
| `js/app.js` | 畫面繪製、互動、同步排程 |
| `js/store.js` | GitHub 讀寫、衝突合併、權杖管理 |
| `data.json` | 設備清單資料本體 |
| `photos/` | 上傳的設備照片 |
| `sw.js` | Service Worker，離線快取（不快取 `data.json` 與 GitHub API） |
| `manifest.json`／`icon-*.png` | PWA 設定與圖示 |
| `.nojekyll` | 讓 GitHub Pages 原樣輸出，不跑 Jekyll |
