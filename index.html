怎麼拿到編輯權杖
  1. 到 GitHub → Settings → Developer settings → Fine-grained tokens
  2. Generate new token，Repository access 選 Only select repositories，只勾這一個 repo
  3. Repository permissions → Contents 設為 Read and write
  4. 產生後複製貼到下面
權杖存在這台裝置的瀏覽器裡。能打開這個瀏覽器的人就能取得它，也就等於能改這個 repo。共用電腦請用完按「清除權杖」。
